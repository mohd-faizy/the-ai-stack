# 77 - Privacy-Preserving AI

> Privacy-Preserving AI focuses on algorithms, cryptographic protocols, and distributed architectures that train, fine-tune, and query machine learning models without exposing underlying sensitive or confidential raw data. Key paradigms include Federated Learning, Differential Privacy, and Secure Multi-Party Computation / Homomorphic Encryption.
