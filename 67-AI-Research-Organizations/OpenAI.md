# OpenAI

> OpenAI: Creators of GPT-4, ChatGPT, DALL-E, Whisper, CLIP, and pioneers of test-time reasoning models (o1, o3).

## 🎯 What to Learn

- Foundation breakthroughs: The GPT series (GPT-1, GPT-2, GPT-3, GPT-4, GPT-4o), scaling laws, and in-context learning
- Reasoning models: OpenAI o1 and o3, pioneering test-time compute scaling and reinforcement learning over chain-of-thought
- Multimodal breakthroughs: CLIP (Contrastive Language-Image Pretraining), DALL-E (diffusion image generation), and Whisper (speech recognition)
- Standardizing developer interfaces: The OpenAI API format (`/v1/chat/completions`), JSON structured outputs, and function calling
- RLHF (Reinforcement Learning from Human Feedback): Pioneering InstructGPT and human preference alignment
- Open-source contributions: Whisper, CLIP, Triton (GPU kernel language), tiktoken, and Point-E
