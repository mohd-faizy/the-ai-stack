# Anthropic

> Anthropic: Creators of the Claude model family, Constitutional AI, Mechanistic Interpretability, and leaders in AI safety research.

## 🎯 What to Learn

- The Claude model family: Claude 3.5 Sonnet, Claude 3 Opus, and Claude 3 Haiku setting industry benchmarks for coding and reasoning
- Constitutional AI: Self-critique and training models using written principles and rules without human feedback bottlenecks (RLAIF)
- Mechanistic Interpretability leadership: Deconstructing neural networks, discovering induction heads, and mapping monosemantic features with Sparse Autoencoders
- Computer Use: Pioneering API capabilities enabling frontier models to control mouse, keyboard, and screen like a human
- Context engineering: 200,000+ token context windows, prompt caching (reducing latency by 80%), and batch processing
- AI alignment philosophy: Responsible Scaling Policy (RSP) and scalable oversight
