# Full-Stack GenAI Application Platforms & Web UIs

> Production platforms and web interfaces that integrate LLMs, RAG, visual workflow builders, multi-modal capabilities, and team collaboration into ready-to-deploy applications.

## 🎯 What to Learn

- Visual orchestration of LLM pipelines, prompt chaining, and tool integrations
- Self-hosted enterprise ChatGPT alternatives: LibreChat, Open WebUI, and Dify
- Multi-tenant user authentication, RBAC, API key management, and token quota tracking
- Integrating multimodal vision, document parsing, and RAG into unified web interfaces
- Observability and tracing inside full-stack platforms: Langfuse, Phoenix, and OpenTelemetry
- Deploying scalable, containerized GenAI stacks with Docker Compose and Kubernetes

## 🧭 Recommended Learning Path

1. Deploy Open WebUI locally and connect it to Ollama for offline private AI chat.
2. Study Dify's visual workflow builder: trigger nodes, LLM nodes, conditional branches, and HTTP requests.
3. Configure enterprise RAG: chunking settings, hybrid keyword/vector search, and re-ranking.
4. Implement user authentication and rate limiting for multi-tenant deployments.
5. Integrate Langfuse or Phoenix for end-to-end trace tracking, cost analysis, and user feedback collection.
