# Generative UI & Frontend Builders

> Generative UI dynamically synthesizes, renders, and streams interactive user interface components and complete frontend applications directly from natural language.

## 🎯 What to Learn

- The Generative UI paradigm: moving beyond raw text to interactive React/HTML/Tailwind components
- Vercel AI SDK Core & UI: streaming UI components, server actions, and `render` lifecycle
- Open-source v0 clones: openv0, Claude Artifacts replicas, and web container code sandboxes
- Sandboxed runtime execution: WebContainers, Sandpack, and Dockerized iframe code runners
- Component design systems and design tokens for constrained LLM UI generation
- Self-correcting UI generation: parsing linter errors and AST validation in the feedback loop

## 🧭 Recommended Learning Path

1. Understand streaming text vs streaming structured UI components in React.
2. Explore Vercel AI SDK `useChat` and tool invocation with UI returns.
3. Integrate Sandpack or WebContainers to execute arbitrary generated React code safely in client browsers.
4. Enforce UI design consistency by injecting shadcn/ui and Tailwind CSS tokens into system prompts.
5. Implement AST syntax tree validation to catch unclosed JSX tags before rendering.
