# Cloud AI SDKs

> Official software development kits and programmatic APIs to provision, manage, train, and deploy AI workloads across major hyperscaler cloud platforms.

## 🎯 What to Learn

- AWS SDK (boto3) & SageMaker Python SDK: Managing training jobs, processing jobs, and real-time endpoints
- Google Cloud Vertex AI SDK (`google-cloud-aiplatform`): Custom training, Gemini API calls, and AutoML pipelines
- Azure Machine Learning SDK (`azure-ai-ml`): Workspace management, compute targets, and MLflow integration
- Cost optimization: Leveraging spot instances, auto-stop on idle, and reserved GPU instances
- Identity and Access Management (IAM): Role-based access control, secure VPC endpoints, and data encryption
- Infrastructure as Code (IaC): Provisioning cloud AI infrastructure with Terraform and Pulumi

## 🧭 Recommended Learning Path

1. Understand cloud shared responsibility models and IAM roles.
2. Write scripts using `boto3` to manage S3 datasets and EC2 compute.
3. Launch a managed training job using the SageMaker PyTorch Estimator.
4. Deploy a trained model to a SageMaker Serverless Inference endpoint.
5. Automate cloud infrastructure provisioning using Terraform.
