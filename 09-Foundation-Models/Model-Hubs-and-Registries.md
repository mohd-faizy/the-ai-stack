# Model Hubs & Registries

> Model hubs and registries provide versioned, open-weights distribution, model cards, evaluations, and community discovery for the global AI ecosystem.

## 🎯 What to Learn

- The open-weights distribution pipeline: Git LFS, chunked shards, and metadata headers
- Hugging Face Hub architecture: model repositories, dataset registries, and Spaces hosting
- Model cards: documenting intended use, training dataset provenance, limitations, and evaluation metrics
- Ollama Model Library and Modelfiles: containerizing weights, system prompts, and quantization parameters
- Security in model registries: scanning for malicious pickle payloads, safetensors enforcement, and license compliance

## 🧭 Recommended Learning Path

1. Set up Hugging Face CLI authentication using user access tokens.
2. Download models locally with caching management (`HF_HOME`).
3. Write a comprehensive model card documenting evaluation benchmarks, hardware used, and biases.
4. Create custom Modelfiles in Ollama with system prompts and temperature settings.
5. Audit model weights for security, strictly using `.safetensors` format.
