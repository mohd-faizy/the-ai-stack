# Distillation

> Knowledge distillation techniques, logit matching, intermediate representation transfer, and reasoning trace distillation from large teacher models to compact student models.

## 🎯 What to Learn

- Knowledge Distillation (KD) fundamentals: Teacher-student framework, soft targets, and temperature scaling ($T$)
- Loss formulation: Combining soft cross-entropy loss (KL divergence with teacher logits) with hard ground-truth loss
- TextBrewer (AIR-IAP): PyTorch-based knowledge distillation toolkit designed specifically for natural language processing
- Classic distilled models: DistilBERT (40% smaller, 60% faster, 97% performance), TinyBERT, and MiniLM
- Reasoning trace distillation: Training 1.5B - 14B student models on synthesized `<think>` reasoning traces from frontier models (DeepSeek-R1 Distill)
- Self-distillation and feature-based distillation across intermediate transformer layers

## 🧭 Recommended Learning Path

1. Understand 'dark knowledge': Why class probabilities reveal information about inter-class similarity.
2. Implement the distillation loss function: $mathcal{L}_{KD} = alpha T^2 	ext{KL}(p_T || p_S) + (1 - alpha) 	ext{CE}(y, p_S)$.
3. Train a small student model with TextBrewer matching teacher hidden representations.
4. Explore reasoning trace distillation: Training student models on chain-of-thought outputs.
5. Evaluate inference latency speedups on CPU and mobile devices.
