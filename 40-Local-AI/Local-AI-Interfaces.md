# Local AI Interfaces

> Modern, feature-rich web and desktop user interfaces designed to interact with local and self-hosted AI models with rich chat features.

## 🎯 What to Learn

- Open WebUI: Self-hosted ChatGPT-like UI with Ollama integration, RAG, role-based access, and model builder
- Jan: Privacy-first open-source desktop alternative to ChatGPT running 100% offline
- LibreChat: Multi-model, multi-provider web interface supporting OpenAI, Anthropic, Ollama, and plugins
- LobeChat: Modern design framework with agent market, TTS/STT, and multimodal plugins
- Managing local chat histories, SQLite databases, and user authentication
- Streaming responses via Server-Sent Events (SSE) and WebSocket protocols

## 🧭 Recommended Learning Path

1. Understand the architecture of AI web interfaces: Frontend (React/Svelte), Backend API, and Model Engine.
2. Deploy Open WebUI using Docker: `docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway ghcr.io/open-webui/open-webui:main`.
3. Connect Open WebUI to your local Ollama daemon.
4. Try Jan or Chatbox for a zero-Docker native desktop experience.
5. Configure web search extensions (SearXNG) and local document RAG inside Open WebUI.
