# Research Tools

> Academic search engines, open bibliographic databases, and paper-code linking platforms that empower researchers to discover literature efficiently.

## 🎯 What to Learn

- Semantic Scholar: AI-powered scientific literature search engine with citation intent classification and Semantic Reader
- OpenAlex: Massive open index of 250M+ scholarly works, authors, institutions, and citation graphs
- Papers With Code: The definitive community platform linking research papers to their official GitHub repositories and evaluation leaderboards
- Connected Papers: Visual tool that generates local citation and co-citation similarity graphs for any paper
- Arxiv Sanity Preserver: Karpathy's tool for filtering, sorting, and following daily computer science preprints
- Querying academic APIs with Python to construct custom research feeds

## 🧭 Recommended Learning Path

1. Master the three-pass reading technique for academic papers.
2. Use Papers With Code to track state-of-the-art benchmarks in your domain.
3. Explore citation neighborhoods using Connected Papers to find overlooked seminal work.
4. Query the OpenAlex REST API in Python to gather author h-indices and institution graphs.
5. Set up personalized RSS/Discord feeds from ArXiv and Semantic Scholar.
