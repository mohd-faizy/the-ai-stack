# Essential AI Repositories

> If you only have a few minutes, start here.

### Core Frameworks

* [PyTorch](https://github.com/pytorch/pytorch) — Deep learning framework with dynamic computational graphs.
* [TensorFlow](https://github.com/tensorflow/tensorflow) — End-to-end machine learning platform.
* [JAX](https://github.com/jax-ml/jax) — High-performance numerical computing and machine learning.
* [scikit-learn](https://github.com/scikit-learn/scikit-learn) — Machine learning in Python.
* [Transformers](https://github.com/huggingface/transformers) — State-of-the-art pretrained models.
* [OpenCV](https://github.com/opencv/opencv) — Computer vision library.
* [Keras](https://github.com/keras-team/keras) — High-level deep learning API.

### LLM Essentials

* [llama.cpp](https://github.com/ggml-org/llama.cpp) — Efficient local LLM inference in C/C++.
* [vLLM](https://github.com/vllm-project/vllm) — High-throughput LLM serving engine.
* [DeepSpeed](https://github.com/deepspeedai/DeepSpeed) — Deep learning optimization and distributed training.
* [Megatron-LM](https://github.com/NVIDIA/Megatron-LM) — Large-scale transformer training.
* [Ollama](https://github.com/ollama/ollama) — Run LLMs locally with one command.

### Generative AI Essentials

* [Diffusers](https://github.com/huggingface/diffusers) — Diffusion models for images, audio, and 3D.
* [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — Modular node-based generative AI workflows.
* [FLUX.1](https://github.com/black-forest-labs/flux) — Next-generation open-weights image generation foundation model.
* [Dify](https://github.com/langgenius/dify) — Production-grade LLM app development and visual workflow platform.
* [Stable Diffusion WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui) — Most popular web interface for local image generation.

### Agent Essentials

* [LangGraph](https://github.com/langchain-ai/langgraph) — Stateful, multi-actor agent orchestration framework.
* [OpenHands](https://github.com/OpenHands/OpenHands) — Autonomous AI software development and computer-use agent.
* [CrewAI](https://github.com/crewAIInc/crewAI) — Multi-agent role-playing orchestration framework.
* [AutoGen](https://github.com/microsoft/autogen) — Multi-agent conversational and event-driven framework by Microsoft.
* [PydanticAI](https://github.com/pydantic/pydantic-ai) — Model-agnostic, production-ready agent framework with Python type safety.
* [browser-use](https://github.com/browser-use/browser-use) — Connect AI agents to web browsers for autonomous navigation.
* [Mem0](https://github.com/mem0ai/mem0) — Scalable memory layer for personalized AI agents.
* [Model Context Protocol](https://github.com/modelcontextprotocol) — Open standard for connecting AI models to data sources and tools.

# Contributing

Contributions are welcome, but this is a **curated list**, not a directory of every AI repository on GitHub.

Before submitting a repository, please consider:

* Is it genuinely useful?
* Is it open source?
* Is it actively maintained?
* Does it have meaningful adoption or community interest?
* Does it have research or industry significance?
* Does it provide something substantially different from existing entries?
* Is it relevant to the category?
* Is the repository itself high quality?

Please avoid submitting:

* Abandoned repositories
* Personal experiments with little adoption
* Duplicate projects
* Forks without substantial changes
* Low-quality wrappers
* Repositories that merely call an AI API
* Spam or promotional repositories
* Projects included solely because they have many stars

The goal is **quality over quantity**.
