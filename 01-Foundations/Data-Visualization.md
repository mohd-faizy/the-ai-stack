# Data Visualization

> Data visualization translates complex numerical features, model predictions, high-dimensional latent representations, and training dynamics into actionable visual insight.

## 🎯 What to Learn

- Exploratory Data Analysis (EDA) plotting distributions, correlations, and outliers
- Declarative vs imperative visualization paradigms (Matplotlib vs Seaborn vs Altair)
- Interactive data exploration and browser-based dashboards (Plotly, Streamlit, Panel)
- High-dimensional embedding projections: t-SNE, UMAP, and PCA visualizations
- Visualizing loss surfaces, training curves, confusion matrices, and ROC/PR curves
- Rapid web demonstration deployment for ML models with Gradio and Streamlit

## 🧭 Recommended Learning Path

1. Master core figure anatomy in Matplotlib: Figure, Axes, Spines, and Ticks.
2. Use Seaborn for statistical plotting: distributions (KDE, boxplots) and categorical relationships.
3. Create interactive web visualizations using Plotly express.
4. Build model demo interfaces using Gradio and Streamlit.
5. Deploy interactive 2D/3D projections of high-dimensional embeddings using UMAP and PCA.
