# 64 - Emerging AI

> Test-time compute scaling, reinforcement-learned chain-of-thought reasoning, self-improving agents, embodied physical intelligence, and agentic operating platforms.

## 🌐 Overview & Architectural Importance

The frontier of AI is shifting from passive next-token prediction to test-time reasoning and physical embodiment. Breakthroughs like DeepSeek-R1, OpenAI o1, Open-R1, and LeRobot prove that allocating compute during inference for reflection, backtracking, and self-correction unlocks superhuman reasoning and enables physical robots to learn dextrous tasks.

## 🧭 Recommended Study Sequence

1. **Test-Time Compute Scaling**: Trading latency and token count for superior reasoning accuracy.
2. **Reinforcement Learning for Reasoning**: DeepSeek-R1, Group Relative Policy Optimization (GRPO), and Open-R1.
3. **Autonomous Code Fixing**: Self-evaluating execution traces and Docker testing with OpenHands and SWE-agent.
4. **Physical Robot Teleoperation**: Collecting demonstration datasets and training diffusion policies with LeRobot.
5. **Enterprise Agent Platforms**: Low-code visual agent lifecycle deployment with Dify and Langflow.

## 🗝️ Foundational Prerequisites

- Reinforcement learning from verifiable rewards (RLVR, PPO, GRPO).
- Transformer decoding dynamics and hidden reasoning tokens (`<think>` tags).
- Robotics concepts: Joint angles, end-effector coordinates, and action chunking.
