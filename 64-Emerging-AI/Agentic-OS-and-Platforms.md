# Agentic OS & Platforms

> Visual application development platforms, unified agent runtimes, and low-code orchestration frameworks that manage the full lifecycle of enterprise AI agents.

## 🎯 What to Learn

- The Agentic OS concept: Process scheduling, memory persistence, tool registry, and permission sandboxes for AI agents
- Dify.ai: Open-source visual LLM app development platform combining prompt orchestration, RAG pipelines, and visual workflow builders
- Langflow: Open-source visual framework for building multi-agent systems and RAG pipelines with Python export
- Flowise: Drag-and-drop UI to build customized LLM flows with LangChain and LlamaIndex
- SuperAGI: Open-source autonomous AI framework to build, manage, and run multi-agent applications
- Enterprise agent governance: Multi-tenant RBAC, audit logging, model failover, and telemetry instrumentation

## 🧭 Recommended Learning Path

1. Understand why developer platforms shifted from raw code scripts to visual orchestration canvases.
2. Deploy Dify locally using Docker Compose: `docker compose up -d`.
3. Build a visual workflow combining conditional branching, LLM generation, and web search tools.
4. Index documents into Dify's built-in hybrid RAG engine (vector + keyword search).
5. Publish your agent as an embeddable web widget or REST API for external applications.
