# General Machine Learning

> The core paradigm of learning mathematical mappings from observed empirical data, spanning classification, regression, and tree ensembles.

## 🎯 What to Learn

- Supervised vs unsupervised vs semi-supervised learning paradigms
- Linear regression, regularized regression (L1 Lasso, L2 Ridge, ElasticNet)
- Logistic regression, odds ratios, decision boundaries, and cross-entropy loss
- Decision trees: impurity measures (Gini, Entropy), pruning, and split criteria
- Ensemble methods: bagging (Random Forests) and boosting (AdaBoost, Gradient Boosting)
- Modern GBDTs: XGBoost (exact greedy & histogram), LightGBM (GOSS, EFB), CatBoost (ordered boosting)
- Model evaluation: Cross-validation, ROC-AUC, PR-AUC, F1-Score, Brier score, and calibration curves

## 🧭 Recommended Learning Path

1. Understand linear & logistic regression mathematically, including gradient derivations and loss functions.
2. Master tree-based algorithms from single decision trees to random forests and gradient boosted ensembles.
3. Study GBDT algorithms: compare the histogram split algorithm of LightGBM with CatBoost's target encoding.
4. Implement robust evaluation metrics: ROC-AUC, PR-AUC, calibration plots, and stratified k-fold splits.
5. Deploy models with pipeline serialization, input validation, and inference latency benchmarks.
