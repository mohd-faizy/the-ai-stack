# 02 - Machine Learning

> Statistical pattern recognition, classical learning algorithms, automated feature extraction, and tabular intelligence systems.

## 🌐 Overview & Architectural Importance

Despite the surge in deep learning, classical machine learning—particularly gradient-boosted trees, regularized linear models, and sophisticated feature engineering—remains the undisputed champion for structured tabular business data, low-latency prediction systems, and small-data regimes across global industries.

## 📑 Curated Learning Guides

Explore in-depth roadmaps, authoritative textbooks, official documentation, courses, and implementations for each subtopic:

* [**General Machine Learning**](General-Machine-Learning.md) — Scikit-learn, XGBoost, LightGBM, CatBoost, and fundamental supervised & unsupervised algorithms.
* [**AutoML**](AutoML.md) — Automated hyperparameter optimization, neural architecture search, and ensembling pipelines.
* [**Time Series**](Time-Series.md) — Forecasting algorithms, ARIMA, Prophet, deep neural forecasting, and temporal feature extraction.
* [**Recommender Systems**](Recommender-Systems.md) — Collaborative filtering, matrix factorization, two-tower retrieval networks, and ranking algorithms.
* [**Anomaly Detection**](Anomaly-Detection.md) — Outlier detection, isolation forests, one-class SVMs, and temporal anomaly scoring.
* [**Clustering**](Clustering.md) — Density-based clustering (HDBSCAN), centroid methods (K-Means), and manifold learning (UMAP, t-SNE).
* [**Feature Engineering**](Feature-Engineering.md) — Automated feature generation, categorical encoding, feature stores (Feast), and selection methods.

## 🧭 Recommended Study Sequence

1. **Classical Foundations**: Linear/logistic regression, decision trees, random forests, and boosting.
2. **Gradient Boosting Mastery**: In-depth study of XGBoost, LightGBM, and CatBoost objective functions and splits.
3. **Unsupervised & Geometry**: K-Means, HDBSCAN, PCA, and UMAP for latent structure discovery.
4. **Domain-Specific ML**: Time series forecasting (Darts, StatsForecast) and Recommender Systems (RecBole, Implicit).
5. **Production ML Pipelines**: Feature engineering, automated validation, and feature stores.

## 🗝️ Foundational Prerequisites

- Linear algebra (matrix-vector multiplication, dot products).
- Basic probability distributions and hypothesis testing.
- Python data manipulation with Pandas and NumPy.
