# Workflow Automation

> Visual workflow automation platforms, self-hosted integration engines, and event-driven systems that connect AI models to hundreds of external business applications.

## 🎯 What to Learn

- n8n: Fair-code licensed workflow automation platform with 400+ native integrations, visual canvas, and advanced AI agent nodes
- Activepieces: Open-source no-code business automation alternative to Zapier, built with TypeScript
- Node-RED: Flow-based development tool for visual programming of event-driven IoT and web applications
- Windmill: Open-source developer platform turning Python, TypeScript, and SQL scripts into workflows and internal UIs
- Webhook architecture: Webhook listeners, payload transformations, error handling, and exponential retry policies
- Self-hosting automation stacks on Docker and Kubernetes with secure credential management

1. Understand the mechanics of HTTP webhooks and JSON event payloads.
2. Deploy n8n locally using Docker: `docker run -it --rm --name n8n -p 5678:5678 n8nio/n8n`.
3. Connect an OpenAI node to parse and summarize text dynamically.
4. Add an AI Agent node with a vector database retrieval tool in n8n.
5. Deploy production workflows with automated failure notifications via Telegram/Slack.
