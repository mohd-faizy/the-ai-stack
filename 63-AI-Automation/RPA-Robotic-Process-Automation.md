# RPA (Robotic Process Automation)

> Desktop automation engines, headless browser automation, and computer-vision-driven RPA frameworks that bridge modern AI with legacy enterprise software.

## 🎯 What to Learn

- RPA fundamentals: Automating repetitive tasks across desktop applications, terminal emulators, and legacy web interfaces
- RPA Framework (Robocorp / Sema4.ai): Open-source Python ecosystem of libraries for robotic process automation
- TagUI: Open-source cross-platform command-line tool for digital process automation with human-readable syntax
- Computer vision in RPA: Template matching and OCR (OpenCV/PaddleOCR) to click buttons on remote desktop and Citrix sessions
- Headless browser automation with Playwright and Selenium
- Exception handling, process logging, and audit trails in regulated enterprise environments

## 🧭 Recommended Learning Path

1. Understand the difference between API automation and UI automation (RPA).
2. Install `rpaframework` in Python and automate basic Excel spreadsheet operations.
3. Automate browser interactions using Playwright and RPA Framework Browser libraries.
4. Automate legacy Windows desktop applications using UI Automation (UIA) selectors.
5. Pair AI vision models (OCR and multimodal LLMs) with RPA to handle dynamic, unstructured documents.
