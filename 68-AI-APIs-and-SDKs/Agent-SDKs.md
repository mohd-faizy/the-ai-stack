# Agent SDKs

> Type-safe agent frameworks, multi-agent communication runtimes, and developer toolkits engineered specifically for autonomous agent creation.

## 🎯 What to Learn

- PydanticAI: Production agent framework by the Pydantic team bringing type-safe validation, dependency injection, and model independence to agents
- OpenAI Agents SDK: Lightweight framework for orchestrating multi-agent handoffs and tool execution
- Vercel AI SDK: The premier TypeScript/JavaScript library for building streaming conversational web apps and agents
- Semantic Kernel (Microsoft): Enterprise-grade SDK integrating AI with C#, Python, and Java applications
- Agent handoffs: Passing control, conversation state, and context between specialized sub-agents
- Dependency injection: Providing runtime database connections, user credentials, and tools safely to agent functions

## 🧭 Recommended Learning Path

1. Understand why loose string-based agents break in production.
2. Learn PydanticAI's `Agent[DepsType, ResultType]` type annotation pattern.
3. Inject database connections and user context via dependency injection.
4. Explore Vercel AI SDK for full-stack React streaming and generative UI.
5. Implement multi-agent handoffs with the OpenAI Agents SDK.
