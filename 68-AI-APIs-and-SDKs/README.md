# 68 - AI APIs & SDKs

> Official provider SDKs, agent-oriented development kits, and unified multi-provider routing gateways.

## 🌐 Overview & Architectural Importance

Connecting software systems to artificial intelligence requires robust client libraries, type-safe agent SDKs, and multi-provider routing layers. From PydanticAI and Vercel AI SDK to LiteLLM gateways, developer SDKs handle streaming, retries, tool execution, and token observability.

## 📑 Curated Learning Guides

Explore in-depth roadmaps, authoritative textbooks, official documentation, courses, and implementations for each subtopic:

* [**LLM Provider SDKs**](LLM-Provider-SDKs.md) — OpenAI, Anthropic, Google GenAI, Cohere, Mistral, Groq, and official foundation model clients.
* [**Agent SDKs**](Agent-SDKs.md) — OpenAI Agents SDK, PydanticAI, Semantic Kernel, LangChain, and Vercel AI SDK.
* [**Multi-Provider Gateways**](Multi-Provider-Gateways.md) — LiteLLM, OpenRouter, Portkey, Helicone, AI Gateway, and unified model routing.

## 🧭 Recommended Study Sequence

1. **Provider Client Fundamentals**: Authentication, streaming responses, and exponential backoff.
2. **Type-Safe Agent Development**: PydanticAI and OpenAI Agents SDK for deterministic schema validation.
3. **Multi-Provider Multiplexing**: Routing requests across OpenAI, Anthropic, and Groq with LiteLLM.
4. **Enterprise AI Gateways**: Rate limiting, virtual keys, budget tracking, and caching.
5. **Frontend AI Integration**: Streaming text and UI components with Vercel AI SDK.

## 🗝️ Foundational Prerequisites

- Python / TypeScript async/await programming patterns.
- Pydantic and TypeScript type systems.
- RESTful API design, headers, and bearer token authentication.
