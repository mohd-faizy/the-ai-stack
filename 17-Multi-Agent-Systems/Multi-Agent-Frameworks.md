# Multi-Agent Frameworks

> Multi-Agent Frameworks provide the communication topologies, role assignment protocols, and consensus mechanisms required to orchestrate teams of collaborative language agents.

## 🎯 What to Learn

- Conversational multi-agent patterns (Microsoft AutoGen)
- Role-playing teams and task handoffs (CrewAI)
- Software company simulation architectures (MetaGPT, ChatDev)
- Hierarchical supervisor vs. peer-to-peer decentralized networks
- Agent swarms and lightweight dynamic handoffs (OpenAI Swarm)

## 🧭 Recommended Learning Path

1. Learn the limitations of single-agent prompting and when multi-agent separation of concerns is needed.
2. Implement a two-agent dialogue (Researcher and Critic) using Microsoft AutoGen.
3. Configure GroupChat with a manager agent to coordinate multi-agent turns dynamically.
4. Incorporate Standardized Operating Procedures (SOPs) inspired by MetaGPT.
5. Add human oversight to approve final team outputs before deployment.
