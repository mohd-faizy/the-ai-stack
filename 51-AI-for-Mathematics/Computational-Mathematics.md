# Computational Mathematics

> Computer algebra systems, symbolic mathematical computation libraries, and high-performance numerical ecosystems.

## 🎯 What to Learn

- Symbolic vs Numerical computation: Exact analytical manipulation vs floating-point approximations
- SageMath: Open-source mathematics software system combining NumPy, SciPy, SymPy, Maxima, and GAP
- Julia Language: High-performance, dynamically typed scientific programming language solving the two-language problem
- SymPy: Python library for symbolic mathematics (calculus, algebra, discrete math, and physics)
- SciML (Scientific Machine Learning in Julia): DifferentialEquations.jl and automated differentiation ecosystems
- Exact arbitrary-precision arithmetic and polynomial ring computations

## 🧭 Recommended Learning Path

1. Understand when to use symbolic computation (exact solutions) vs numerical approximation.
2. Use SymPy in Python to solve equations, compute Taylor series, and compute symbolic integrals.
3. Explore SageMath for advanced number theory and algebraic geometry calculations.
4. Learn Julia's multiple dispatch and write high-performance matrix algorithms.
5. Explore the SciML ecosystem for scientific simulation and physics-informed learning.
