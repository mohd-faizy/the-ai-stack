# Theorem Proving

> Interactive proof assistants, formal languages, and mathematical verification engines that mathematically guarantee the correctness of mathematical proofs and software.

## 🎯 What to Learn

- The Curry-Howard correspondence: Propositions as types, proofs as programs
- Lean 4: Modern interactive theorem prover and functional programming language developed at Microsoft Research
- Mathlib: The massive unified mathematical library of Lean, formalizing algebra, topology, and analysis
- Isabelle/HOL: Higher-Order Logic proof assistant widely used in computer science verification and mathematics
- Coq: Formal proof management system based on the Calculus of Inductive Constructions
- Tactic-based proving: `rw`, `apply`, `simp`, `induction`, `linarith`, and automated goal resolution

## 🧭 Recommended Learning Path

1. Play the Natural Number Game to learn basic tactics (`intro`, `apply`, `exact`, `rw`).
2. Install Lean 4 and VS Code with the Lean extension.
3. Read through Mathematics in Lean, practicing real number analysis and algebra proofs.
4. Explore Mathlib4 to understand how modern undergraduate mathematics is organized.
5. Formalize your own lemmas and contribute to open mathematical repositories.
