# Evolutionary Algorithms

> Evolutionary Algorithms are population-based stochastic optimization techniques inspired by biological evolution that iteratively select, recombine, and mutate candidate solutions to solve non-convex, multimodal optimization problems.

## 🎯 What to Learn

- Genetic Algorithms (GA): Chromosome representations, crossover operators, and mutation rates
- Covariance Matrix Adaptation Evolution Strategy (CMA-ES)
- Multi-objective evolutionary optimization (NSGA-II, Pareto fronts)
- Differential Evolution (DE) for continuous global optimization
- Evolutionary computation frameworks: DEAP, PyGAD, and Nevergrad

## 🧭 Recommended Learning Path

1. Learn basic genetic algorithm components: population, fitness function, selection (roulette wheel, tournament).
2. Implement a simple GA from scratch in Python to solve a combinatorial puzzle.
3. Master CMA-ES for non-convex continuous parameter optimization.
4. Study Pareto dominance and implement NSGA-II for multi-objective trade-offs.
5. Apply Nevergrad to tune deep learning hyperparameters without computing gradients.
