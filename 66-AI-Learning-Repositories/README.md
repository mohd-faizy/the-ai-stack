# 66 - AI Learning Repositories

> Curated open-source courses, comprehensive roadmaps, hands-on textbooks, and definitive community knowledge repositories.

## 🌐 Overview & Architectural Importance

The sheer velocity of artificial intelligence can overwhelm learners. Curated open-source learning repositories provide structured pedagogical paths—from mathematics for machine learning to deep learning from scratch, LLMs, AI agents, and diffusion models.

## 🧭 Recommended Study Sequence

1. **Foundational Mathematics**: Linear algebra, multivariable calculus, and probability.
2. **Classical Machine Learning**: Scikit-learn, feature engineering, and model evaluation with ML for Beginners.
3. **Deep Learning Foundations**: PyTorch, backpropagation, and CNNs/RNNs with fast.ai and D2L.
4. **Large Language Models from Scratch**: Pre-training, fine-tuning, and alignment with Sebastian Raschka's guide.
5. **Autonomous Agent Engineering**: Multi-agent systems, tools, memory, and orchestration.

## 🗝️ Foundational Prerequisites

- Python programming proficiency (OOP, decorators, type hints).
- High school calculus and linear algebra.
- Git version control and command line navigation.
