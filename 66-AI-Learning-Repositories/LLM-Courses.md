# LLM Courses

> Hands-on engineering guides, from-scratch coding books, and comprehensive roadmaps for mastering Large Language Models.

## 🎯 What to Learn

- The LLM Course (Maxime Labonne): Comprehensive GitHub curriculum covering LLM architecture, fine-tuning, quantization, and deployment
- LLMs-from-scratch (Sebastian Raschka): Official code repository for building a real, working ChatGPT-like LLM step-by-step in pure PyTorch
- Hands-on LLMs: Open-source tutorials covering prompt engineering, RAG, PEFT fine-tuning, and evaluation
- LLM Zoomcamp (DataTalks.Club): Free engineering course on building real-world production LLM systems
- Tokenization, causal attention masks, multi-query attention (MQA), and Rotary Position Embeddings (RoPE)
- Supervised instruction tuning (SFT) and preference alignment (DPO)

## 🧭 Recommended Learning Path

1. Study tokenization and embedding representations.
2. Build causal multi-head self-attention from scratch in PyTorch.
3. Assemble the transformer blocks with LayerNorm and feed-forward networks.
4. Pre-train on a small corpus and generate text autoregressively.
5. Instruction fine-tune the model using LoRA and evaluate with standard benchmarks.
