# Machine Learning Courses

> Curated open-source machine learning courses, comprehensive learning roadmaps, and production engineering curriculums.

## 🎯 What to Learn

- Made With ML (Goku Mohandas): Production-grade ML engineering course covering design, data, training, tracking, and deployment
- Microsoft ML for Beginners: 12-week, 26-lesson curriculum with visual sketches and hands-on Scikit-learn notebooks
- Homemade Machine Learning (Oleksii Trekhleb): Popular machine learning algorithms implemented from scratch in pure Python with math explanations
- Mathematics for Machine Learning (Deisenroth et al.): Foundational linear algebra, vector calculus, and probability
- The Machine Learning Roadmap: Comprehensive visual guide navigating from zero knowledge to industry engineering
- Classical supervised and unsupervised algorithms: Decision Trees, Random Forests, XGBoost, and K-Means

## 🧭 Recommended Learning Path

1. Complete Andrew Ng's Machine Learning Specialization for conceptual mastery.
2. Work through Microsoft ML for Beginners notebooks to practice Scikit-learn.
3. Read Aurélien Géron's Hands-On Machine Learning (Part 1).
4. Follow Goku Mohandas' Made With ML to master production deployment and MLOps.
5. Compete in a Kaggle tabular competition to test your skills.
