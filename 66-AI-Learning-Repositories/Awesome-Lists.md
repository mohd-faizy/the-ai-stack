# Awesome Lists

> Curated community directories, categorized link libraries, and living indexes tracking state-of-the-art tools, papers, and libraries across the AI ecosystem.

## 🎯 What to Learn

- Awesome Machine Learning: The foundational GitHub awesome list cataloging ML frameworks across 15+ programming languages
- Awesome LLM: Regularly updated directory of large language model papers, datasets, frameworks, and evaluation tools
- Awesome Generative AI: Curated collection of modern generative AI applications, models, and infrastructure
- Awesome AI Agents: Curated directory tracking autonomous agents, frameworks, papers, and benchmarks
- Awesome ChatGPT Prompts: Massive community collection of system prompts, roleplay personas, and jailbreaks
- How to effectively navigate, filter signal-over-noise, and contribute to open-source awesome repositories

## 🧭 Recommended Learning Path

1. Bookmark foundational lists: Awesome Machine Learning, Awesome LLM, and Awesome AI Agents.
2. Use search filters (e.g. `is:pr is:merged`) to see what new libraries are being accepted.
3. Audit links before adopting libraries: Check stars velocity, last commit date, and issue response times.
4. Follow the contributing guidelines to submit high-quality resources to community lists.
5. Build custom thematic index lists for your specific domain.
