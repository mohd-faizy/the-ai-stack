# Deep Learning Courses

> Open textbooks, interactive video series, and university lecture courses teaching deep learning from first principles to state-of-the-art models.

## 🎯 What to Learn

- Dive into Deep Learning (D2L.ai): Open-source interactive textbook with code in PyTorch, JAX, and TensorFlow
- Practical Deep Learning for Coders (fast.ai): Jeremy Howard's top-down, code-first course making deep learning accessible
- Neural Networks: Zero to Hero (Andrej Karpathy): Masterclass building micrograd, backpropagation, and transformers from scratch
- MIT 6.S191: Introduction to Deep Learning (Alexander Amini): Fast-paced annual university course covering the state of the art
- The Deep Learning Book (Goodfellow, Bengio, Courville): The foundational theoretical academic text
- Core architectures: Multilayer Perceptrons, Convolutional Networks (ResNet), and Transformers

## 🧭 Recommended Learning Path

1. Build a scalar autograd engine by watching Karpathy's `micrograd` video.
2. Work through the fast.ai Practical Deep Learning for Coders course.
3. Read through Dive into Deep Learning (D2L.ai) to deepen mathematical understanding.
4. Complete Andrew Ng's Deep Learning Specialization on Coursera.
5. Implement ResNet-50 and Vision Transformers from scratch in PyTorch.
