# AI Agents Courses

> Curated learning paths, multi-agent frameworks, and practical tutorials teaching how to build autonomous, tool-using AI agent systems.

## 🎯 What to Learn

- The anatomy of an AI Agent: Brain (LLM) + Memory (Short/Long term) + Tools (APIs) + Planning (Decomposition/Reflection)
- Agent design patterns: ReAct (Reason + Act), Plan-and-Solve, Self-Refinement, and Multi-Agent Collaboration
- Microsoft AI Agents for Beginners: 10-lesson open-source curriculum exploring multi-agent patterns with AutoGen
- LangGraph tutorials: Building stateful, cyclic multi-agent graphs with human-in-the-loop controls
- Tool invocation mechanics: Schema validation, error recovery, and structured outputs
- Multi-agent communication topologies: Hierarchical teams, round-robin debate, and peer collaboration

## 🧭 Recommended Learning Path

1. Understand the ReAct pattern: Interleaving thought, action, and observation steps.
2. Complete DeepLearning.AI's Multi AI Agent Systems with crewAI.
3. Study LangGraph's stateful cyclic graphs and state persistence.
4. Implement human-in-the-loop approval gates before critical actions.
5. Deploy an autonomous multi-agent pipeline to production.
