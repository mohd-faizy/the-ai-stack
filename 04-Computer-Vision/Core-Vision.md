# Core Computer Vision

> Foundational image processing, coordinate transformations, spatial filtering, feature detection, and classical OpenCV algorithms.

## 🎯 What to Learn

- Image representation: channels (RGB, BGR, HSV, Grayscale), bit-depth, and coordinate spaces
- Spatial filtering: Gaussian blur, median blur, Sobel, Laplacian, and Canny edge detection
- Morphological operations: dilation, erosion, opening, closing, and hit-or-miss transforms
- Feature extraction: Harris corners, SIFT, SURF, ORB, and feature matching (RANSAC)
- Affine and projective transformations, homography, perspective warping, and camera calibration
- Convolution arithmetic: receptive field calculation, stride, padding, and dilation

## 🧭 Recommended Learning Path

1. Master image color spaces (BGR, RGB, HSV) and basic slicing with NumPy.
2. Apply spatial convolutions: Gaussian blur, Sobel gradients, and Canny edge detection.
3. Extract contours, bounding rectangles, and convex hulls from thresholded binary masks.
4. Compute camera matrix calibration and perspective warps using homography.
5. Transition from classical kernels to learned 2D convolutional layers in PyTorch.
