# Web Crawling & Scraping

> Web crawling and scraping tools extract, clean, and convert live internet data and dynamic JavaScript applications into structured, LLM-ready markdown.

## 🎯 What to Learn

- The evolution of scraping: from static HTML parsing (BeautifulSoup) to headless browser automation (Playwright)
- Crawl4AI: open-source asynchronous web crawler engineered specifically to output LLM-ready clean Markdown
- Bypassing modern web obstacles: JavaScript rendering, infinite scrolls, dynamic shadow DOMs, and popups
- Scrapy framework: asynchronous spider architecture, middlewares, and pipelines for large-scale crawling
- HTML-to-Markdown conversion and noise extraction: stripping boilerplate navigation, ads, and footers
- Robots.txt etiquette, rate-limiting, proxy rotation, and legal scraping compliance

## 🧭 Recommended Learning Path

1. Understand static HTTP requests (Requests) vs dynamic headless browser execution (Playwright).
2. Inspect DOM trees using CSS selectors and XPath queries.
3. Deploy Crawl4AI to asynchronously extract clean, boilerplate-free Markdown from web URLs.
4. Implement rate-limiting and session handling to respect target servers.
5. Use LLM extraction schemas in Crawl4AI to parse unstructured web pages directly into typed Pydantic models.
