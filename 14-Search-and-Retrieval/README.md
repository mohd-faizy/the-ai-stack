# 14 - Search & Retrieval

> Information retrieval, inverted index search engines, automated web crawling, and semantic search architectures.

## 🌐 Overview & Architectural Importance

Information Retrieval (IR) is the science of locating relevant knowledge from massive unstructured repositories. In the generative AI era, classic lexical search (BM25) and dense neural retrieval have converged into hybrid search architectures—ensuring that AI agents and RAG pipelines retrieve precise keyword matches alongside conceptual semantic relationships.

## 📑 Curated Learning Guides

Explore in-depth roadmaps, authoritative textbooks, official documentation, courses, and implementations for each subtopic:

* [**Search Engines**](Search-Engines.md) — Elasticsearch, OpenSearch, Meilisearch, and full-text inverted index engines with BM25 scoring.
* [**Web Crawling & Scraping**](Web-Crawling-and-Scraping.md) — Crawl4AI, Scrapy, Playwright, and extracting clean, LLM-ready markdown from modern dynamic web apps.
* [**Semantic Search**](Semantic-Search.md) — ColBERT multi-vector late interaction, SPLADE sparse representations, and hybrid lexical-dense ranking.

## 🧭 Recommended Study Sequence

1. **Lexical Search Foundations**: Inverted index, tokenization, stemming, TF-IDF, and BM25 scoring.
2. **Web Ingestion Pipelines**: Headless browser automation (Playwright), scraping (Scrapy), and LLM web crawlers (Crawl4AI).
3. **Late Interaction Architectures**: ColBERT token-level embeddings and MaxSim operator.
4. **Learned Sparse Representations**: SPLADE for vocabulary-space expansion and term weighting.
5. **Hybrid Fusion**: Combining keyword and vector retrieval with Reciprocal Rank Fusion (RRF).

## 🗝️ Foundational Prerequisites

- Information retrieval metrics: Precision@k, Recall@k, MAP, and NDCG.
- HTTP protocols, DOM trees, CSS selectors, and JavaScript rendering.
- Linear algebra and token-level matrix operations.
