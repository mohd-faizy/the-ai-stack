# Search Engines

> Full-text search and information retrieval engines built on inverted indexes, providing typo tolerance, faceted filtering, and BM25 relevance scoring.

## 🎯 What to Learn

- The Inverted Index: posting lists, term frequencies, and document offsets
- Relevance scoring: BM25 (Best Matching 25) vs TF-IDF mathematics
- Typo tolerance and fuzzy matching using Levenshtein distance and n-grams
- Meilisearch: ultra-fast, developer-friendly Rust search engine for front-end instant search
- Elasticsearch & OpenSearch: distributed, enterprise full-text search with vector capabilities
- Faceted navigation, aggregations, and multi-field boosting

## 🧭 Recommended Learning Path

1. Understand the inverted index: mapping unique terms to sorted lists of document IDs.
2. Study BM25 scoring: term saturation, document length normalization, and inverse document frequency.
3. Deploy Meilisearch using Docker and configure searchable attributes, ranking rules, and stop words.
4. Implement faceted search to allow users to filter by category, date, and price.
5. Compare BM25 lexical search with dense vector search to understand when exact keyword matching is essential.
