# 69 - AI Developer Tooling

> Terminal CLI assistants, modern development environments, reactive computational notebooks, rapid UI builders, and configuration managers.

## 🌐 Overview & Architectural Importance

Building AI systems requires a modern developer toolbelt—pairing terminal coding assistants (Aider, Ollama) with next-generation reactive notebooks (Marimo), interactive UI prototyping frameworks (Streamlit, Gradio), and robust configuration engines (Hydra) to manage complex experiments.

## 📑 Curated Learning Guides

Explore in-depth roadmaps, authoritative textbooks, official documentation, courses, and implementations for each subtopic:

* [**CLI Tools**](CLI-Tools.md) — Aider, Ollama CLI, llama.cpp, sgpt, llm (Simon Willison), and mods terminal assistants.
* [**Development Environments**](Development-Environments.md) — VS Code, Cursor, Zed, Marimo reactive notebooks, JupyterLab, and cloud IDEs.
* [**AI App Frameworks**](AI-App-Frameworks.md) — Streamlit, Gradio, Chainlit, Panel, Mesop, and NiceGUI for rapid AI prototyping.
* [**Configuration & Experiment Management**](Configuration-and-Experiment-Management.md) — Hydra, OmegaConf, gin-config, and hierarchical configuration management.

## 🧭 Recommended Study Sequence

1. **Terminal AI Engineering**: Git-integrated pair programming in the terminal with Aider.
2. **Next-Gen Reactive Notebooks**: Eliminating hidden notebook state with Marimo.
3. **Rapid Frontend Prototyping**: Building multi-page streaming interfaces with Streamlit and Gradio.
4. **AI-Native Editors**: Cursor and Zed for codebase-wide semantic navigation.
5. **Hierarchical Experiment Configuration**: Managing multi-GPU sweeps with Hydra and OmegaConf.

## 🗝️ Foundational Prerequisites

- Command-line literacy (Bash, zsh, terminal shortcuts).
- Python development environments (virtualenvs, uv, poetry).
- YAML and hierarchical configuration structures.
