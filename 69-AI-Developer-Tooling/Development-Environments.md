# Development Environments

> Modern code editors, reactive computational notebooks, and AI-native IDEs engineered for rapid machine learning development.

## 🎯 What to Learn

- Marimo: Next-generation reactive Python notebook that guarantees reproducible execution with zero hidden state
- Cursor: AI-native code editor built on VS Code with codebase indexing, multi-file edits, and inline generation
- Zed: High-performance multiplayer code editor written in Rust with native AI model integration
- VS Code & Remote Development: Developing inside Docker containers and remote GPU instances via SSH
- The hidden state problem in traditional Jupyter: Out-of-order cell execution causing silent bugs
- Interactive debugger workflows: Breakpoints, variable inspection, and tensor profiling

## 🧭 Recommended Learning Path

1. Understand the dangers of out-of-order cell execution in traditional Jupyter notebooks.
2. Install Marimo: `pip install marimo` and run `marimo tutorial intro`.
3. Experience reactive data dependencies: Updating cell A automatically updates cell B.
4. Explore Cursor or Zed for AI-native codebase editing and contextual chat.
5. Configure VS Code Remote-SSH to edit code seamlessly on cloud GPU clusters.
