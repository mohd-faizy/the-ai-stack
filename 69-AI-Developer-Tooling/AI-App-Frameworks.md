# AI App Frameworks

> Rapid web application frameworks, Python UI libraries, and interactive prototyping tools designed specifically for AI and data science applications.

## 🎯 What to Learn

- Streamlit: The most popular pure-Python framework for building data and AI web applications with built-in chat elements
- Gradio (Hugging Face): Specialized framework for showcasing machine learning models with interactive inputs/outputs and Spaces hosting
- Chainlit: Developer framework for building conversational ChatGPT-like interfaces with multi-modal uploads and step tracing
- NiceGUI & Mesop (Google): Lightweight, pythonic UI frameworks for internal tools and web apps
- Panel (HoloViz): High-performance dashboarding library capable of handling large datasets and complex visualizations
- State management, reactive caching, and deploying to cloud infrastructure

## 🧭 Recommended Learning Path

1. Understand the differences between Streamlit (dashboards/apps), Gradio (model demos), and Chainlit (conversational bots).
2. Build a simple chat interface using `st.chat_message` and `st.chat_input` in Streamlit.
3. Create a computer vision demo with Gradio's `gr.Image` and `gr.Label`.
4. Use session state (`st.session_state`) to persist conversation history across reruns.
5. Deploy your interactive app on Streamlit Community Cloud or Hugging Face Spaces.
