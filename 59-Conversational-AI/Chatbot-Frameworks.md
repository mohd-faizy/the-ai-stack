# Chatbot Frameworks

> Conversational application frameworks, visual drag-and-drop builders, and developer toolkits to build, test, and deploy intelligent chatbots.

## 🎯 What to Learn

- Chainlit: Fast Python framework for building ChatGPT-like conversational UIs with streaming, file uploads, and step visualization
- Langflow & Flowise: Visual low-code drag-and-drop interfaces for composing LangChain chains, agents, and vector databases
- Rasa: Enterprise open-source conversational AI framework with natural language understanding (NLU) and dialogue management
- Typebot: Open-source conversational form and lead-generation chatbot builder with visual flow editor
- Streaming tokens over WebSockets and Server-Sent Events (SSE)
- Managing multi-turn session state, conversation persistence, and human agent handoff

## 🧭 Recommended Learning Path

1. Understand the mechanics of streaming token generation via WebSockets.
2. Build a conversational assistant using Chainlit's `@cl.on_message` decorator.
3. Explore Langflow or Flowise to visually prototype complex retrieval chains.
4. Integrate conversational memory to handle multi-turn context retention.
5. Deploy to cloud environments with Docker and secure user authentication.
