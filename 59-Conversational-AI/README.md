# 59 - Conversational AI

> Chatbot engineering frameworks, ultra-low-latency real-time voice agents, dialogue state management, and visual workflow builders.

## 🌐 Overview & Architectural Importance

Conversational AI has evolved from rigid intent-classifier rule engines to fluid, sub-second latency voice-to-voice agents. Platforms like LiveKit, Pipecat, and Chainlit enable real-time speech interaction, interruptibility, and dialogue management powering enterprise customer assistants and human-like copilots.

Explore in-depth roadmaps, authoritative textbooks, official documentation, courses, and implementations for each subtopic:

* [**Chatbot Frameworks**](Chatbot-Frameworks.md) — Rasa, Chainlit, Flowise, Langflow, Typebot, and conversational application builders.
* [**Voice Agents & Real-Time AI**](Voice-Agents-and-Real-Time-AI.md) — LiveKit Agents, Pipecat, Vocode, Retell AI, sub-500ms voice agents, and WebRTC streaming.

## 🧭 Recommended Study Sequence

1. **Conversational UI Prototyping**: Building chat applications in pure Python with Chainlit.
2. **Visual Agent Builders**: Drag-and-drop conversational workflows with Flowise and Langflow.
3. **Real-Time Voice Architecture**: WebRTC transport, Voice Activity Detection (Silero VAD), and streaming STT/TTS.
4. **Ultra-Low Latency Orchestration**: Building sub-500ms voice pipelines with LiveKit Agents and Pipecat.
5. **Dialogue State Tracking**: Managing multi-turn slots, entity resolution, and deterministic policy rollouts.

## 🗝️ Foundational Prerequisites

- WebSockets and WebRTC protocols for bidirectional real-time audio streaming.
- Speech-to-Text (STT) and Text-to-Speech (TTS) pipeline latency budgets.
- Asynchronous Python programming (`asyncio`).
