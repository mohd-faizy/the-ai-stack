# Dialogue Management

> Dialogue state tracking, conversational policy optimization, and multi-turn slot filling architectures for task-oriented conversational agents.

## 🎯 What to Learn

- Dialogue systems architecture: Natural Language Understanding (NLU) -> Dialogue State Tracking (DST) -> Dialogue Policy -> Natural Language Generation (NLG)
- Rasa Core: Story-based dialogue management combining rule-based policies with machine learned conversation paths
- Dialogue State Tracking (DST): Maintaining beliefs about user goals and filled slots across long multi-turn sessions
- ConvLab-2: Open-source multi-domain dialogue system platform for training and evaluating task-oriented agents
- Meta ParlAI: Unified platform for sharing, training, and evaluating conversational models across multi-turn benchmarks
- Graceful error recovery, confirmation dialogues, and handling ambiguous user intents

## 🧭 Recommended Learning Path

1. Understand the classic task-oriented dialogue pipeline (NLU -> DST -> Policy -> NLG).
2. Learn slot-filling mechanics and form validation in conversational agents.
3. Build multi-turn conversation flows using Rasa stories and deterministic rules.
4. Explore how modern LLMs handle dialogue state tracking via in-context memory vs explicit state machines.
5. Deploy interactive evaluation pipelines to measure task completion rates.
