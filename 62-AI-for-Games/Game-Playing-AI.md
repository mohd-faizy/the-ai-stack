# Game Playing AI

> Superhuman game-playing systems, Monte Carlo Tree Search, model-based reinforcement learning, and imperfect-information game theory.

## 🎯 What to Learn

- DeepMind MuZero: Mastering chess, shogi, Go, and 57 Atari games without knowledge of the underlying rules or game dynamics
- Monte Carlo Tree Search (MCTS): Selection, Expansion, Simulation (Rollout), and Backpropagation
- OpenSpiel (DeepMind): Comprehensive framework for reinforcement learning and search in games (poker, backgammon, chess)
- PySC2 (StarCraft II Learning Environment): DeepMind's environment for mastering real-time multi-agent strategy games (AlphaStar)
- Imperfect information games: Counterfactual Regret Minimization (CFR) and solving Texas Hold'em (Libratus, Pluribus)
- Model-based RL: Learning a representation function, dynamics function, and prediction function

## 🧭 Recommended Learning Path

1. Understand Minimax and Alpha-Beta pruning in two-player zero-sum games.
2. Master the 4 phases of Monte Carlo Tree Search: Selection (PUCT), Expansion, Evaluation, and Backup.
3. Explore AlphaZero: Combining MCTS with a dual-head policy and value neural network.
4. Study MuZero: Learning internal hidden state dynamics rather than reconstructing full pixel observations.
5. Experiment with imperfect information games (Poker) using OpenSpiel and CFR.
