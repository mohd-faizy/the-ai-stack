# 62 - AI for Games

> Reinforcement learning game environments, procedural content generation, game-playing algorithms, and generative non-player characters (NPCs).

## 🌐 Overview & Architectural Importance

Games are the premier proving ground for artificial intelligence—from AlphaZero mastering chess and Go to MuZero planning without rules, and Voyager exploring Minecraft autonomously with LLMs. AI for games spans agent training (Unity ML-Agents), procedural world generation, and autonomous dynamic NPCs.

Explore in-depth roadmaps, authoritative textbooks, official documentation, courses, and implementations for each subtopic:

* [**Game AI Frameworks**](Game-AI-Frameworks.md) — Unity ML-Agents, Godot RL Agents, Griddly, DeepMind Lab, and game engine RL environments.
* [**Game Generation & Procedural Content**](Game-Generation-and-Procedural-Content.md) — Voyager, MineDojo, Procgen, GVGAI, and procedural world and level generation.

## 🧭 Recommended Study Sequence

1. **Game Engine RL**: Training agents in Unity using ML-Agents and PyTorch PPO/SAC.
2. **Open-World Exploration**: Autonomous curriculum learning in Minecraft with Voyager and MineDojo.
3. **Model-Based RL & Search**: Mastering games with unknown rules using MuZero and MCTS.
4. **Multi-Agent Game Theory**: Imperfect information games (poker, StarCraft) with OpenSpiel and PySC2.
5. **Generative NPCs**: Simulating believable human behaviors and long-term memory in interactive virtual worlds.

## 🗝️ Foundational Prerequisites

- Reinforcement learning (Markov Decision Processes, PPO, SAC, reward shaping).
- Game engine fundamentals (Unity C# or Godot GDScript).
- Search algorithms: Minimax, Alpha-Beta pruning, and Monte Carlo Tree Search (MCTS).
