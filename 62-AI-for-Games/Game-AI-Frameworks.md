# Game AI Frameworks

> Open-source toolkits that transform video game engines into reinforcement learning simulation environments with Python APIs.

## 🎯 What to Learn

- Unity ML-Agents: Toolkit that enables games and simulations made in Unity to serve as environments for training intelligent agents via PyTorch
- Godot RL Agents: Open-source reinforcement learning package for the Godot game engine
- Griddly: Ultra-fast grid-world game engine designed for reinforcement learning research and procedural generation
- DeepMind Lab: 3D first-person game-like platform developed for agent navigation and memory research
- Vectorized parallel environments: Running 32+ game instances simultaneously to accelerate RL sample collection
- Observation spaces: Raycasts, visual camera inputs, and vector states with discrete and continuous action spaces

## 🧭 Recommended Learning Path

1. Understand the basics of the Unity game engine (GameObjects, Rigidbodies, C# scripts).
2. Install the `mlagents` Python package and Unity package.
3. Define agent observations (Raycast sensor vs camera rendering) and actions.
4. Design reward signals: Balancing dense intermediate rewards with sparse goal rewards.
5. Train agents across 16 parallel game instances and export the trained ONNX model back into Unity.
