# NPC & Character AI

> Generative non-player characters (NPCs), believable behavioral simulations, conversational agents, and cognitive architectures for virtual worlds.

## 🎯 What to Learn

- Generative Agents (Stanford 'Smallville'): Simulating 25 autonomous AI agents living in a virtual town with memory, daily plans, and social interactions
- Cognitive architecture for NPCs: Memory Stream -> Reflection -> Planning -> Reactive Execution
- Inworld AI: Character engine for interactive virtual characters with emotional states, speech, and multimodal gestures
- Character.AI: Large-scale conversational platform modeling millions of distinct personas, fictional characters, and conversational styles
- Behavior Trees vs LLM-driven decision making: Combining deterministic game logic with natural language dialog
- Preventing immersion-breaking hallucinations and maintaining consistent character backstory lore

## 🧭 Recommended Learning Path

1. Understand why static pre-written dialog trees limit player freedom in games.
2. Study the Generative Agents cognitive architecture: Memory Stream, Reflection, and Planning.
3. Implement memory retrieval scored by: `score = recency + importance + relevance`.
4. Explore Inworld AI to connect speech, emotional facial expressions, and animations.
5. Bridge LLM dialog with deterministic in-game state changes using function calling.
