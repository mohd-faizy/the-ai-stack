# Web Research & Search

> Web-scale retrieval agents, open search engines, browser automation tools, and web-to-markdown scrapers that feed live data to LLMs.

## 🎯 What to Learn

- Firecrawl (Mendable): Clean, LLM-ready web scraper converting entire websites and dynamic SPAs into clean Markdown
- Perplexica: Open-source AI-powered search engine alternative to Perplexity AI using local LLMs and SearXNG
- SearXNG: Privacy-respecting, open-source metasearch engine aggregating results from 70+ search providers
- browser-use: Open-source framework enabling LLMs to interact with websites, fill forms, and scrape dynamic pages like a human
- Handling dynamic JavaScript SPAs: Headless browsers (Playwright, Puppeteer) vs fast HTTP requests
- Robots.txt compliance, rate-limiting, and resilient scraping architectures

## 🧭 Recommended Learning Path

1. Understand why raw HTML is toxic for LLM context windows (token bloat, scripts, styling).
2. Deploy SearXNG locally with Docker to aggregate search results across Google, Bing, and DuckDuckGo.
3. Use Firecrawl to convert target web pages into clean, noise-free Markdown.
4. Explore `browser-use` for interactive multi-step web navigation (clicking, scrolling, form entry).
5. Deploy Perplexica for a beautiful, private AI search experience.
