# 60 - AI Search & Research Agents

> Autonomous deep research agents, web-scale semantic search engines, recursive crawling tools, and comprehensive multi-source knowledge synthesis pipelines.

## 🌐 Overview & Architectural Importance

Traditional search engines return 10 blue links, forcing humans to manually click, read, filter ads, and synthesize facts. Deep research agents (GPT Researcher, Stanford STORM, Perplexica, Firecrawl) autonomously query the web, scrape dozens of sources, cross-reference claims, and generate long-form, verifiable cited research reports.

## 📑 Curated Learning Guides

Explore in-depth roadmaps, authoritative textbooks, official documentation, courses, and implementations for each subtopic:

* [**Deep Research**](Deep-Research.md) — STORM, GPT Researcher, Open Deep Research, Tavily, AI Scientist, and automated long-form investigation.
* [**Web Research & Search**](Web-Research-and-Search.md) — Perplexica, browser-use, Firecrawl, SearXNG, Khoj, and web-crawling search agents.
* [**Knowledge Synthesis**](Knowledge-Synthesis.md) — Multi-document summarization, cross-referencing, claim verification, and literature synthesis.

## 🧭 Recommended Study Sequence

1. **Search API Integration**: Real-time web retrieval with Tavily, Brave Search, and SearXNG.
2. **Web Crawling for LLMs**: Converting messy HTML into clean markdown with Firecrawl.
3. **Autonomous Research Loops**: Plan-and-execute multi-query exploration with GPT Researcher.
4. **Multi-Perspective Investigation**: Synthesizing diverse viewpoints with Stanford STORM.
5. **Hallucination Verification**: Verbatim quote attribution and source verification.

## 🗝️ Foundational Prerequisites

- REST search APIs and web scraping ethics/rate limits.
- Agent architectures (ReAct, Plan-and-Solve, LangGraph).
- Information retrieval and document reranking.
