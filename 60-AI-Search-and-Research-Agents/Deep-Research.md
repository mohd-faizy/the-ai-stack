# Deep Research Agents

> Autonomous agents that recursively plan, search, browse, cross-reference, and author comprehensive, cited long-form research reports on complex topics.

## 🎯 What to Learn

- The Deep Research loop: Topic decomposition -> Sub-query generation -> Web retrieval -> Content extraction -> Verification -> Long-form synthesis
- GPT Researcher: Open-source autonomous research agent that produces detailed, unbiased research reports with citations in minutes
- Stanford STORM: Generating Wikipedia-like comprehensive articles via multi-perspective expert interviews and outline generation
- Tavily AI: Search engine built specifically for AI agents, returning clean content optimized for LLM context windows
- The AI Scientist (Sakana AI): Fully automated scientific research system from idea generation to paper writing and peer review
- Mitigating confirmation bias and synthesizing contradictory evidence across multiple web sources

## 🧭 Recommended Learning Path

1. Understand why single-prompt LLM web searches produce shallow, hallucinated summaries.
2. Explore the Plan-and-Execute agent architecture: Query breakdown -> Web search -> Reranking.
3. Integrate Tavily or SearXNG for clean markdown web retrieval.
4. Run GPT Researcher locally to generate automated research papers.
5. Add strict source attribution and fact-verification gates before report generation.
