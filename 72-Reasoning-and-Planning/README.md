# 72 - Reasoning & Planning

> Reinforcement-learned reasoning models, hierarchical task decomposition, formal logic engines, and competition mathematical problem solving.

## 🌐 Overview & Architectural Importance

Standard language models generate text by statistical association without internal deliberation. Reasoning and planning frameworks (DeepSeek-R1, Open-R1, LATS, SayCan) give models the capacity to explore search trees, backtrack from dead ends, decompose multi-week goals, and verify intermediate steps.

## 🧭 Recommended Study Sequence

1. **Test-Time Search & Verification**: Evaluating search over reasoning trees (MCTS / Best-First Search).
2. **Reinforcement Learning for Reasoning**: DeepSeek-R1, GRPO, and verifiable rewards.
3. **Hierarchical Task Decomposition**: Breaking long-horizon tasks into subgoals with SayCan and LATS.
4. **Formal Logic Integration**: First-order logic theorem resolution with FOLIO.
5. **Mathematical Mastery**: Solving Olympiad-level math problems with step-by-step verification.

## 🗝️ Foundational Prerequisites

- Reinforcement learning (PPO, GRPO, reward modeling).
- Search algorithms (A*, MCTS, beam search).
- Formal logic (propositional logic, first-order logic, quantifiers).
