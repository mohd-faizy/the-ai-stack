# Task-Specific & Domain Agents

> Task-specific and domain agents are tailored with bespoke tool registries, domain ontologies, and specialized cognitive architectures to perform complex professional workflows in science, finance, engineering, and data analysis.

## 🎯 What to Learn

- The AI Scientist: Automated scientific discovery, literature review, experiment running, and paper generation
- Data Interpreter: Automated data science, feature engineering, and statistical modeling agents
- Software maintenance agents: Automated pull request reviews and vulnerability patching (PR-Agent, Sweep)
- Financial domain agents: Automated market data ingestion, sentiment analysis, and quantitative modeling (FinRobot)
- Domain prompt tuning and specialized tool grounding

## 🧭 Recommended Learning Path

1. Analyze why general-purpose chatbots struggle with domain-specific professional workflows.
2. Study the automated ideation, coding, and review loop of The AI Scientist.
3. Deploy PR-Agent on a GitHub repository to automate code reviews and test generation.
4. Explore FinRobot to construct multi-agent financial equity research workflows.
5. Design custom tools and validation schemas for your specific industry domain.
