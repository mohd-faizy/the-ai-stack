# Autonomous & Self-Directed Agents

> Autonomous and self-directed agents operate continuously over extended horizons, decomposing high-level human directives into sub-goals, modifying environments, and adapting behavior through feedback.

## 🎯 What to Learn

- Long-horizon planning and recursive goal decomposition
- Autonomous development agents (OpenHands, Devin paradigms)
- Embodied and virtual agent environments (Voyager in Minecraft)
- Error recovery, loop detection, and infinite-recursion guardrails
- Cost control, token budget management, and execution timeouts

## 🧭 Recommended Learning Path

1. Understand the anatomy of an autonomous agent: planner, memory, executor, and evaluator.
2. Study the architecture of OpenHands and how it interacts with sandboxed bash environments.
3. Implement loop-detection algorithms to stop agents from repeating failed actions.
4. Integrate dynamic test runners to verify changes before marking tasks complete.
5. Run an evaluation run on SWE-bench Lite to measure real-world problem-solving efficacy.
