# Coding Agents

> Coding agents autonomously navigate entire codebases, write unit tests, debug execution failures, and implement multi-file features directly inside developer environments.

## 🎯 What to Learn

- Aider: CLI pair programmer with git repository mapping and tree-sitter AST parsing
- SWE-agent: Software engineering agent with specialized Agent-Computer Interfaces (ACI)
- OpenHands and Cline/Roo Code: Autonomous coding inside VS Code and web environments
- Repository indexing, symbol resolution, and context window budgeting
- Automated regression testing and commit patch generation

## 🧭 Recommended Learning Path

1. Install Aider and run it against a local Python or TypeScript project.
2. Study tree-sitter AST repository mapping to see how relevant symbols are packed into the context window.
3. Learn SWE-agent's Agent-Computer Interface (custom search, file editing, and test running commands).
4. Configure Cline in VS Code with local or cloud model providers and MCP servers.
5. Build a CI/CD action that automatically generates reproducing tests for incoming bug reports.
