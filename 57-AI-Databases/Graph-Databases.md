# Graph Databases

> Property graph databases, Cypher query engines, and Graph RAG architectures designed to model highly interconnected relationships and knowledge networks.

## 🎯 What to Learn

- Property graph model: Nodes (entities), Edges (relationships), Labels, and key-value Properties
- Neo4j: The world's leading graph database platform with native graph storage and processing
- Cypher Query Language: Declarative ASCII-art pattern matching query language (`MATCH (p:Person)-[:WORKS_AT]->(c:Company)`)
- Memgraph & ArangoDB: High-performance in-memory and multi-model alternatives for graph analytics
- Graph RAG: Combining knowledge graph entity relationships with vector search to answer complex multi-hop questions
- Graph algorithms: PageRank, Louvain community detection, and shortest path traversals

## 🧭 Recommended Learning Path

1. Understand when graph databases outperform relational databases (multi-hop deep relationships).
2. Install Neo4j Desktop or use Neo4j AuraDB cloud.
3. Master the Cypher query language: `CREATE`, `MATCH`, `WHERE`, `RETURN`.
4. Execute community detection algorithms using the Graph Data Science library.
5. Build a Graph RAG system combining vector embeddings with graph traversals.
