# AI Guardrails

> Programmable runtime validation frameworks, policy engines, and execution mediators that enforce topic boundaries, structural contracts, and safety constraints on LLM outputs.

## 🎯 What to Learn

- Guardrail architectures: Pre-execution input validation, post-execution output verification, and streaming filters
- NVIDIA NeMo Guardrails: Colang programmable dialog flows and topical rails
- Guardrails AI: Structural output validation, schema enforcement, and automated re-asking mechanisms
- LLM Guard (Laiyer): Security, PII anonymization, and prompt injection detection
- Topical steering: Ensuring an enterprise assistant stays within customer support boundaries
- Latency overhead management and parallel asynchronous guardrail execution

## 🧭 Recommended Learning Path

1. Understand where guardrails fit in the application lifecycle (Input -> Model -> Output).
2. Learn Guardrails AI for strict JSON output schema validation and auto-healing.
3. Master NVIDIA Colang syntax for topical boundary definition.
4. Implement LLM Guard for real-time PII redaction and jailbreak filtering.
5. Profile latency impact and optimize guardrails with streaming chunk validation.
