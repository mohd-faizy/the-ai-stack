# Vision Evaluation

> Benchmark datasets, evaluation protocols, and multidimensional leaderboards to evaluate computer vision models and Vision-Language Models (VLMs).

## 🎯 What to Learn

- Classic vision metrics: Mean Average Precision (mAP), Intersection over Union (IoU), and Top-1/Top-5 accuracy
- VLM benchmarks: MMBench, MathVista, MMMU, and DocVQA
- Evaluating visual reasoning, diagram understanding, and mathematical geometry
- Fine-grained object detection and dense segmentation: COCO and LVIS benchmarks
- Visual hallucination evaluation: POPE (Polling-based Object Probing Evaluation)
- Multimodal video evaluation: Video-MME and ActivityNet

## 🧭 Recommended Learning Path

1. Master classical CV metrics: IoU, Precision-Recall curves, and mAP@50:95.
2. Understand VLM specific challenges: visual hallucination and positional bias.
3. Implement POPE evaluation to measure object hallucination rates.
4. Run MMBench circular evaluation across multimodal model checkpoints.
5. Evaluate high-resolution document and chart understanding with DocVQA.

## ⭐ Top 3 Resources

1. MMBench (OpenCompass)
