# Educational AI Tools

> Curated open curricula, comprehensive introductory repositories, and AI-driven pedagogical tools designed to teach modern artificial intelligence.

## 🎯 What to Learn

- Socratic tutoring mechanics: Formulating guided scaffolding questions rather than giving immediate answers
- Microsoft AI for Beginners: 12-week, 24-lesson comprehensive curriculum covering symbolic AI, neural networks, and CV/NLP
- Microsoft Generative AI for Beginners: 18-lesson course covering LLMs, prompt engineering, RAG, and agent architectures
- OpenAI Cookbook: Production-grade examples and tutorials for building with OpenAI APIs and embeddings
- Khan Academy Khanmigo: Case study in pedagogical guardrails, student safety, and teacher workflow assistance
- Automated homework grading, rubric alignment, and formative feedback generation

## 🧭 Recommended Learning Path

1. Complete CS50 AI or Microsoft ML for Beginners to understand foundational algorithms.
2. Work through Microsoft Generative AI for Beginners lessons.
3. Experiment with OpenAI Cookbook recipe patterns.
4. Implement pedagogical system prompts with strict Socratic rules.
5. Build educational interactive tools with Streamlit or Gradio.
