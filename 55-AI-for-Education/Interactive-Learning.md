# Interactive Learning

> Computational notebooks, rapid UI prototyping tools, and cloud GPU environments that enable hands-on interactive experimentation with machine learning.

## 🎯 What to Learn

- Project Jupyter: JupyterLab, IPython kernel, interactive widgets (ipywidgets), and reproducible notebooks
- Google Colab: Free cloud-hosted Jupyter environments with GPU/TPU acceleration and Google Drive integration
- Streamlit: Python framework turning data scripts into shareable web applications in minutes with pure Python
- Gradio (Hugging Face): Python library to rapidly demo machine learning models with interactive web UIs and Hugging Face Spaces hosting
- State management in interactive web apps: Session state, caching (`@st.cache_data`, `@st.cache_resource`)
- Embedding interactive visual components into educational courses and research papers

## 🧭 Recommended Learning Path

1. Master Jupyter notebooks and keyboard shortcuts for rapid exploratory analysis.
2. Use Google Colab for GPU-accelerated training without local hardware setup.
3. Build a model demonstration interface using Gradio in under 10 lines of Python.
4. Create full multi-page dashboard applications with Streamlit and session state.
5. Deploy your interactive app for free on Hugging Face Spaces or Streamlit Community Cloud.
