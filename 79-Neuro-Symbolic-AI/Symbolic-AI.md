# Symbolic AI

> Symbolic AI (Classical AI / GOFAI) relies on explicit, human-readable representations of knowledge, formal logic rules, ontologies, and search algorithms to perform automated reasoning and problem solving.

## 🎯 What to Learn

- Propositional logic, First-Order Logic (FOL), and unification algorithms
- Knowledge representation: Semantic networks, Description Logics, and OWL ontologies
- Automated theorem proving, resolution refutation, and forward/backward chaining
- Declarative and logic programming languages (Prolog, Datalog)
- Computer algebra systems and symbolic mathematics (SymPy)

## 🧭 Recommended Learning Path

1. Master propositional logic, truth tables, and Boolean satisfiability (SAT).
2. Transition to First-Order Logic (quantifiers, predicates, functions, and unification).
3. Learn declarative programming fundamentals in SWI-Prolog.
4. Explore description logics, RDF graphs, and OWL ontologies in Stanford Protégé.
5. Implement a backward-chaining rule engine to solve deductive logic problems.
