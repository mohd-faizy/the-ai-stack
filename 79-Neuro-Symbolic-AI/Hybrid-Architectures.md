# Hybrid Architectures

> Hybrid Neuro-Symbolic Architectures combine differentiable neural network representations with formal logical constraints and probabilistic reasoning engines to achieve robust generalization and interpretable inference.

## 🎯 What to Learn

- Differentiable logic and continuous relaxations of Boolean operators (Gödel, Łukasiewicz, Product t-norms)
- Logic Tensor Networks (LTN) and Real Logic frameworks
- DeepProbLog: Neural probabilistic logic programming
- Logical Neural Networks (LNN) by IBM Research
- Neuro-Symbolic Concept Learner (NS-CL) for visual reasoning

## 🧭 Recommended Learning Path

1. Understand the complementary strengths and weaknesses of deep learning vs. symbolic AI.
2. Study continuous t-norms (Gödel, Product, Łukasiewicz) that convert discrete logic into differentiable loss terms.
3. Implement a simple Logic Tensor Network that classifies objects while obeying transitivity constraints.
4. Explore DeepProbLog to blend neural perception with probabilistic Prolog rules.
5. Build a verifiable reasoning system that guarantees outputs satisfy domain-specific safety axioms.
