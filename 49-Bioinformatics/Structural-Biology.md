# Structural Biology

> AI-driven macromolecular structure prediction, multimeric complex modeling, and conformational dynamics simulations.

## 🎯 What to Learn

- Macromolecular complexes: Protein-protein, protein-DNA, protein-RNA, and ligand-protein interactions
- AlphaFold-Multimer: Predicting quaternary structures and binding interfaces of multi-chain complexes
- Chai-1 (Chai Discovery): Multi-modal foundation model for molecular structure prediction across proteins, nucleic acids, and small molecules
- ESMFold: High-throughput single-sequence structure prediction using ESM-2 representations
- Visualizing structural topologies: PyMOL, ChimeraX, and Mol* browser viewer
- Assessing structural interface quality: ipTM (interface predicted TM-score) and PAE matrices

## 🧭 Recommended Learning Path

1. Understand the coordinate format of `.pdb` and `.cif` structure files.
2. Explore 3D protein structures interactively using ChimeraX or Mol*.
3. Learn how Predicted Aligned Error (PAE) plots diagnose domain-level confidence.
4. Run Chai-1 to predict a multi-chain complex with a bound small-molecule ligand.
5. Evaluate interface predicted TM-scores (ipTM) to identify true physical binders.
