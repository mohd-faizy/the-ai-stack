# NLP Frameworks

> Core computational libraries and transformer frameworks that provide model registries, tokenizers, pipelines, and industrial NLP tools.

## 🎯 What to Learn

- Hugging Face Transformers ecosystem: AutoModel, AutoTokenizer, pipeline, and Trainer API
- Industrial NLP with spaCy: processing pipelines, Doc, Span, Token objects, and Cython optimizations
- Model fine-tuning workflows: dataset mapping, padding, dynamic batching, and evaluation metrics
- Model hub navigation, model cards, and open-weights downloads from Hugging Face Hub
- ONNX runtime export and quantization for low-latency CPU/GPU inference
- Difference between encoder-only (BERT), decoder-only (GPT), and encoder-decoder (T5) paradigms

## 🧭 Recommended Learning Path

1. Understand text preprocessing: lowercase, regex cleaning, and stopword trade-offs.
2. Explore spaCy linguistic features: part-of-speech (POS) tagging, dependency parsing, and NER.
3. Master the Hugging Face pipeline API for quick inference across sentiment, summarization, and NER.
4. Fine-tune a pretrained BERT model on a custom classification dataset using `Trainer`.
5. Optimize model inference using ONNX runtime and 8-bit dynamic quantization.
