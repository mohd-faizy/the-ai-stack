# 05 - Natural Language Processing

> Computational linguistics, tokenization, sequence-to-sequence modeling, information extraction, machine translation, and transformer representation learning.

## 🌐 Overview & Architectural Importance

Natural Language Processing (NLP) bridges human language and machine intelligence. By converting unstructured human text into contextual vector embeddings, modern NLP architectures have transformed document analysis, translation, semantic search, and dialogue systems—forming the technological lineage that culminated in modern Large Language Models.

## 🧭 Recommended Study Sequence

1. **Text Preprocessing & Tokenization**: Subword tokenization (BPE, WordPiece), vocabulary building, and special tokens.
2. **Word Embeddings**: Word2Vec, GloVe, FastText, and the transition to contextual representations.
3. **The Transformer Revolution**: Self-attention, multi-head attention, positional encoding, and LayerNorm.
4. **Encoder Architectures**: BERT, RoBERTa, and DeBERTa for classification, NER, and feature extraction.
5. **Sequence-to-Sequence & Generation**: BART, T5, and translation models evaluated with ROUGE and BLEU.

## 🗝️ Foundational Prerequisites

- PyTorch tensor indexing, masking, and padding operations.
- Basic probability, cross-entropy loss, and language modeling concepts.
- Regular expressions and string manipulation in Python.
