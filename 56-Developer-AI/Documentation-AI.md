# Documentation AI

> Automated documentation generators, codebase knowledge management systems, and developer documentation platforms powered by AI.

## 🎯 What to Learn

- The documentation debt problem: Documentation rotting as code changes continuously
- Mintlify: Modern, beautifully designed developer documentation platform with AI-assisted authoring and MDX components
- Swimm: Knowledge management platform that pairs documentation directly with code tokens and auto-syncs when code is refactored
- Automated docstring generation: Synthesizing Google-style, NumPy-style, and Sphinx docstrings using AST-guided LLM prompts
- Extracting architecture diagrams from code with Mermaid.js and LLMs
- Building interactive API documentation with OpenAPI / Swagger specifications

## 🧭 Recommended Learning Path

1. Study Google's Technical Writing principles (active voice, clarity, scannability).
2. Install Mintlify CLI and initialize documentation for a project: `mintlify init`.
3. Explore MDX interactive components (Tabs, Accordions, Response Fields).
4. Learn how Swimm couples markdown documentation to exact code lines to prevent rot.
5. Automate API reference generation directly from OpenAPI/Swagger JSON specs.
