# AI Assistants & Copilots

> Developer copilots, local IDE assistants, and autonomous operating system agents that write code, execute commands, and manage workflows.

## 🎯 What to Learn

- Continue.dev: Leading open-source AI code assistant for VS Code and JetBrains, connecting to any local (Ollama) or cloud model
- Open Interpreter: Natural language computer interface that runs Python, Bash, and AppleScript directly on your local machine
- Khoj: Personal AI copilot connecting to local notes (Obsidian), documents, and calendars with desktop voice chat
- AnythingLLM: All-in-one desktop AI assistant with built-in RAG, vector database, and local model runner
- IDE copilot mechanics: Inline autocomplete, tab-completion models (StarCoder, DeepSeek Coder), and codebase indexing
- Security and sandboxing when giving AI assistants shell and terminal execution privileges

## 🧭 Recommended Learning Path

1. Install Continue.dev in VS Code and connect it to Ollama or Claude.
2. Index your local codebase with Continue's `@Codebase` feature for context-aware code generation.
3. Try Open Interpreter in terminal mode: `interpreter --local` to automate file management.
4. Explore AnythingLLM for desktop document question-answering.
5. Learn best practices for prompt steering and verified test-driven copilot coding.
