# AI Chat Interfaces

> Modern, open-source conversational user interfaces featuring multi-model routing, document RAG, artifact previews, and multi-user authentication.

## 🎯 What to Learn

- Open WebUI: Flagship self-hosted ChatGPT alternative with Ollama, OpenAI, RAG, and pipeline extensions
- LibreChat: Enterprise-grade open-source chat platform supporting OpenAI, Anthropic, Gemini, AWS Bedrock, and plugins
- LobeChat: Modern, beautifully styled conversational framework with visual agent marketplace and multimodal plugins
- Chatbot UI & HuggingChat: Lightweight, customizable chat frontends with clean modern design systems
- Streaming protocols: Implementing Server-Sent Events (SSE) and managing UI auto-scroll during generation
- Interactive artifacts: Rendering live HTML/React previews, charts, and downloadable files in sidebars

## 🧭 Recommended Learning Path

1. Understand Server-Sent Events (SSE) and token streaming in modern web apps.
2. Deploy LibreChat or Open WebUI locally with Docker.
3. Configure multiple model backends (OpenAI API, Anthropic Claude, local Ollama).
4. Implement document drag-and-drop RAG inside the chat interface.
5. Customize themes and user permission tiers.
